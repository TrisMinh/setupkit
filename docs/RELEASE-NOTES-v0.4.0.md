## SetupKit v0.4.0

The first polished public build focused on a safe, lightweight Windows setup flow.

### Highlights

- Verified app catalog with exact winget commands.
- Dry-run mode, command preview, and live terminal output.
- Accent-insensitive search and keyboard shortcut support.
- Smarter rendering so selection changes do not rebuild the whole grid.
- CSS-only motion for cards, dialogs, queue dock, and toasts.
- Better dialog layout, safer selection behavior, and smoother catalog loading.

### Install

Download `SetupKit.exe` from the release assets and run it directly. No installer is required.
