## SetupKit v0.4.1

This release cleaned up the project layout and made installation easier.

### Highlights

- Reorganized the codebase into a Wails + Go structure.
- Moved frontend files into `frontend/` and native logic into `internal/kit/`.
- Added `scripts/install.ps1` for one-command installation from GitHub Releases.
- Reworked README and release packaging.
- Replaced native dropdowns with theme-aware custom controls.
- Fixed duplicate search clear buttons in WebView2.

### Install

Use the one-command PowerShell installer or download `SetupKit.exe` manually.
