## SetupKit v0.6.0

This release focused on catalog browsing and visual polish.

### Highlights

- Added grid, list, and icon catalog views.
- App detail dialogs show the application logo beside the title.
- Fixed selected-app and status icons so they read more clearly.
- Removed translucent selected-app backgrounds that caused WebView2 artifacts.

### Install

Use the one-command PowerShell installer or download `SetupKit.exe` manually.
