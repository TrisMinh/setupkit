## SetupKit v0.8.0

This release turned workspaces into a full first-class surface.

### Highlights

- Added a dedicated Workspaces tab for all 24 role-based plans.
- Added package-detail-style workspace dialogs with counts, sources, app lists, and command previews.
- Workspace cards reveal logo previews on hover or focus.
- Workspace detail lists use denser multi-column rows.
- Icon view buttons align cleanly when names wrap.
- List view now uses empty row space for descriptions and metadata.
- Added ecosystem seed validation to `npm run validate`.

### Install

Use the one-command PowerShell installer or download `SetupKit.exe` manually.
