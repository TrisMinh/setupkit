# App icon assets

Brand SVGs are downloaded from pinned releases of the Simple Icons package.

- Simple Icons: https://github.com/simple-icons/simple-icons
- PowerToys icon: https://github.com/microsoft/PowerToys
- Everything icon: https://www.voidtools.com/

Run `npm run icons:fetch` to refresh the vendored files. Icons are stored locally so the SetupKit interface does not depend on a CDN at runtime.
