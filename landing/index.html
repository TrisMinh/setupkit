The install engine

Mọi thao tác đi qua một đường ray an toàn.

SetupKit không tải script lạ, không nhận package tùy ý và luôn hiện lệnh thật trước khi thay đổi máy.

01

Allowlist nhúng trong binary

Catalog JSON được kiểm chứng lúc build rồi nhúng vào app. Native API từ chối package ID ngoài danh sách.

02

Terminal sống

stdout/stderr của winget stream trực tiếp, progress từng app được suy luận theo output thật.

03

Profiles tái sử dụng

Xuất và nhập bộ app thành hồ sơ JSON để dựng máy mới mà không nhớ lại từng công cụ.

Workspace first

Không bắt đầu từ danh sách app. Bắt đầu từ vai trò.

Developer Core, Web Frontend, Python & AI, Office, Designer, Gaming. Chọn một workspace hoặc tự lọc theo tag/source/status.

v0.9.0 control loops

Cập nhật và rollback không còn là việc mở terminal mò lệnh.

Updates

Quét `winget upgrade`, search app có bản mới, cập nhật từng app hoặc tất cả sau một lần xác nhận.

Versions

Tải version bằng `winget show --versions`, chọn bản cũ và quyết định cài đè hay gỡ rồi cài.

Audit

Luồng nào cũng có confirm, terminal, log, scan lại trạng thái và chỉ chạy package trong allowlist.
